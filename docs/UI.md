# 界面规则

拾雨的界面约定。参考实现是 [prototype/index.html](../prototype/index.html)，搬到 SwiftUI 或加新功能时照这里来；改了规则就同步改原型。通用原则见全局 CLAUDE.md 的 UI 部分，这里只写本项目的具体做法。

## 布局

- 窗口 = 左侧栏 + 主区（工具栏 / 任务列表 / 状态栏）。
- **侧栏**
  - 宽度可拖，范围 160–340px，记住上次宽度；拖动条可聚焦，←/→ 每次调 10px。拖动条从顶栏下沿开始，顶栏高度内留给拖动窗口。
  - 层级：「全部」是一级（加粗）；视频、音频、图片、文档、压缩包、安装包、其他是二级，往右缩进，用竖线 + 圆角折钩挂在「全部」下面，最后一项只有钩、不往下延伸。
  - 自定义分类和「全部」并列（一级加粗），最多三级，子分类同样用竖线 + 折钩挂在父级下；每棵一级分类之间空 10px。
  - 分类右键：新建子分类（满三级时不出现）、重命名（行内输入，回车或失焦保存，Esc 放弃）、删除分类（连子分类一起删，任务不删）。
  - 「新建分类」「设置」固定在侧栏底部，设置快捷键 ⌘,。
- **工具栏**（从左到右）：当前分类名 · 分段控件（全部 / 进行中 / 已完成）· 更新天气 · 全部暂停/继续 · 添加。
- **更新天气**：启动时自动检查一次更新，和设置里的更新检测同步。望云时是乌云，已是最新是太阳，有新版是强调色的雨；没查过或查失败是一朵静止的云。悬停显示状态；有新版时点击把安装包加进下载列表，其余状态点击重新检查。
- **任务行**分三层：文件名 → 3px 进度条 → 一行灰色小字（`速度 · 剩余 · 已下 / 总大小`）。操作按钮（暂停/继续/重试/在访达中显示、删除）平时隐藏，悬停或键盘聚焦时出现。
- **任务归类**：把任务行拖到侧栏分类上（目标行淡强调色底），或右键「移到分类」（缩进的分类列表）/「不放进分类」。
- **删除任务**：行上的垃圾桶或右键「删除…」，底部出确认条（提示的同一位置，深色底，「取消」「删除」，Esc 取消，文件名过长截中间）。已下完的文件移到废纸篓，没下完的连临时文件一起删；右键「从列表移除」只删记录、保留文件。
- **文件图标**：圆角方块，扩展名大写字母，分类色字 + 同色 14% 淡底。
- **状态栏**只写 `N 个下载中 · 总速度`，没有下载时留空。
- 空状态：没有任务时提示「把链接拖进来，或按 ⌘N」；筛选后没结果提示「没有符合条件的任务」。

## 颜色与字体

- 系统字体，正文 13px；次要信息 11.5px 次要色；数字用等宽数字（tabular-nums）。
- 所有颜色走 token。主题四套：跟随系统（浅 / 深两套，强调色系统蓝）、热带雨林（深绿底、翠绿强调）、初夏橙皮（奶油底、橙色强调）、雨后栀子（象牙白底、灰绿强调）。
- 主题的半透明 token（悬停、线条、轨道、折钩、输入框、焦点环）都由同一个墨色按固定透明度调出，加新主题只填底色、文字、强调色和墨色。
- 强调色只用在：主按钮、打开的开关、下载中的进度条、选中背景（强调色 15%）、下拉菜单悬停。
- **字号**：正文 12 / 13 / 14 / 15 / 16 px 可选，默认 13；其他字号按「正文 ÷ 13」的比例一起缩放。
- **背景图**：用户自选图片铺满窗口。取图片平均亮度，亮图配深色字 + 白色半透明蒙版，暗图配浅色字 + 黑色蒙版，保证字看得清；强调色仍用主题的。
- **语言**：中文 / English，默认跟随系统；所有界面文字和类型子文件夹名都跟着切。
- 进度条：下载中强调色 / 暂停、排队灰色 / 失败红色（失败行的小字也变红）。
- 分类色：视频紫、音频粉、图片橙、文档蓝、压缩包棕、安装包和其他灰。

## 动效

| 场景 | 做法 | 时长 |
|---|---|---|
| 侧栏同级切换、分段控件切换 | 选中背景滑过去 | 0.28s |
| 侧栏跨级切换（全部 ↔ 分类） | 旧位置淡出，新位置淡入，同时进行 | 0.22s |
| 切换筛选后的列表 | 逐行淡入并上移 6px，每行错开 22ms，最多错开 12 行 | 0.26s |
| 弹窗 | 遮罩淡入，弹窗从 96% 放大到 100% 并淡入 | 0.2s |
| 下拉菜单 | 在按钮下方展开，下移 4px 淡入 | 0.14s |
| 更新天气 | 望云时乌云左右飘 1.5pt（来回循环）；天晴时太阳转 45° 放大淡入；有新雨时三滴雨错开 0.3s 下落淡出，落三轮后停在云下；状态文字淡入 | 1.6s / 0.5s / 0.9s / 0.22s |

- 下载进度刷新只改数字和进度条宽度，不重建列表、不播入场动画。
- 首次显示时滑块直接就位，不播过渡。
- 系统开启「减弱动态效果」时全部动画关闭。

## 交互

- **添加**：点 `+` 或 ⌘N 打开居中弹窗，多行粘贴链接（只认 http/https），⌘Enter 提交，Esc 或点外面关闭；一个链接都没识别到时在输入框下方红字提示。
- **拖拽**：把链接拖进窗口直接添加，拖动时窗口内描一圈强调色边框。
- **重名**：自动改成 `名字 (1).扩展名`。
- **排队**：同时下载数到上限后新任务排队；调小上限时多出来的任务退回排队。
- **设置**分两页（分段控件切换，页内容不播动画）：
  - 常规：下载位置、同时下载（1–8 个）、每个任务分段（自动 / 2 / 4 / 8 / 16）、按类型放进子文件夹、学习我的分类习惯、完成后通知、在菜单栏显示、接管浏览器下载（右侧显示「已连接 Chrome」或「未连接」+「连接」按钮）、更新检测（「当前 x.y」+「检查更新」→ 乌云 +「正在望云…」→ 太阳 +「天晴 · 已是最新」或下雨 +「新雨已至 · x.y」+ 主按钮「接住新雨」，点了把 .dmg 加进下载列表；失败红字 +「重试」）。
  - 外观：主题、字号、背景图（选择… / 移除）、语言。
  - 下拉一律自绘，开关自绘（32×19 胶囊，开时强调色）。
- **学习分类习惯**：每次手动归类给这个任务的特征投一票，自动归错被挪走时给原分类扣一票，票数 60 天减半。特征分三层，越具体越先判断，一层有把握就用：
  1. 文件内容：JSON 顶层字段、PNG 里嵌的数据标签（角色卡的 `chara`）——下完才有
  2. 来源页面、下载链接路径前两段（Discord 频道）、文件名里的词（中文按相邻两字）
  3. 网站、扩展名
  - 有把握 = 这一层里赢家占 ≥70% 的票，且至少一个特征给它投了 ≥2.5 票。
  - 添加时按链接先猜一次，下完按内容再判一次，猜对了就把文件挪进分类文件夹，并提示一句依据（如「已按习惯归入『世界书』· 文件内容相似」）。手动归过的任务不再自动改。
- **浏览器接管**：Chrome 系扩展拦下下载，经本机宿主交给 App，任务直接加进列表，App 不抢焦点。
  - 装法只剩用户拖一下：点「连接」→ App 把扩展放进 Application Support 的「拾雨扩展.bundle」（不放下载文件夹，免得清理时被删；访达里显示为一个文件，拖不到里面的单个文件），在访达里选中，并用浏览器（默认浏览器是 Chrome 系就用它）打开扩展页，同时提示「打开开发者模式，把文件夹拖进去」。
  - 宿主由 App 每次启动自动注册；设置开着时每 2 秒读一次连接记录，拖进去后自动变成「已连接」。连上后按钮改叫「重新连接」，一直留着：扩展被删或浏览器重装后记录不会过期，要能重新拖一次。
- **菜单栏面板**（仿 Vorssaint）：菜单栏图标下载时旁边显示总速度。点开是 320 宽的圆角面板：顶部 logo，两个图标标签（下载中 / 已完成，选中是淡强调色底并滑动），灰色小标题，圆角卡片里最多 6 行紧凑任务，底部两个等宽描边按钮「打开拾雨」「退出」。设置里关掉菜单栏图标后，关窗口即退出。

## 焦点与选中

- 不出现浏览器 / 系统默认的蓝色焦点框、点按高亮。
- 输入框聚焦：只把边框稍微加深。
- 键盘焦点（Tab 切换）：2px 中性色细环；鼠标点击不显示。

## 搬到 SwiftUI 的对应

| 原型 | SwiftUI |
|---|---|
| 侧栏 + 主区 | 隐藏标题栏 + 自绘 `HStack`（不用 `NavigationSplitView` 和系统工具栏：浮动侧栏会错位、按钮样式和动画对不上原型） |
| 同级滑块 | `matchedGeometryEffect` |
| 跨级淡入淡出 | `.transition(.opacity)` |
| 居中弹窗 | 自定义 overlay + `.scaleEffect` / `.opacity` 过渡 |
| 自绘下拉 | `Menu` 或自定义 popover，不用默认 `Picker` 样式 |
| 减弱动态效果 | `@Environment(\.accessibilityReduceMotion)` |
| 主题 / 语言 | `Theme` 结构 + `@Entry` 环境值，由 `Themed` 修饰器注入；不在根部加 `.tint`（会和 AppKit 外观互相触发、卡死） |
| 菜单栏面板 | `MenuBarExtra(.window)`；`App.body` 里不读任何可观察状态，否则改设置会递归崩溃 |
